Contexto:

1. Tema
Programação Orientada a Objetos em Java: construindo um sistema de gestão de veículos.

2. Contextualização
Uma empresa de locação de veículos deseja desenvolver um sistema para cadastrar e gerenciar os veículos disponíveis para seus clientes.

O sistema deverá permitir o cadastro de diferentes tipos de veículos, como carros e motocicletas, armazenando informações específicas de cada veículo e possibilitando a realização de operações como consulta de dados, cálculo do valor da diária e exibição das informações.

Para desenvolver o sistema, os estudantes deverão aplicar os principais conceitos da Programação Orientada a Objetos (POO) utilizando a linguagem Java.

Durante a atividade, os alunos deverão perceber que diferentes tipos de veículos possuem características e comportamentos próprios, mas também compartilham informações comuns. Dessa forma, será necessário utilizar classes, atributos privados, encapsulamento, métodos get e set, herança, polimorfismo e sobrecarga de métodos.

3. Situação-problema

A empresa TechRent Veículos possui diversos veículos para locação, porém atualmente os dados são controlados manualmente.

A empresa contratou sua equipe de desenvolvimento para criar uma primeira versão de um sistema em Java que permita cadastrar e consultar seus veículos.

O sistema deverá representar diferentes veículos, considerando que:

Todo veículo possui marca, modelo, ano e valor da diária.

Um carro possui uma quantidade de portas.

Uma motocicleta possui cilindrada.

Os dados dos objetos não devem ser acessados diretamente de fora das classes.

O sistema deverá permitir alterar e consultar os dados dos veículos.

Cada tipo de veículo poderá apresentar suas informações de uma maneira específica.

O valor da diária poderá ser calculado de diferentes formas.

O programa deverá demonstrar que um objeto de uma classe filha pode ser tratado como um objeto da classe pai.

Desafio

Como desenvolver um sistema em Java que represente diferentes tipos de veículos utilizando os princípios da Programação Orientada a Objetos?

4. Objetivos de aprendizagem

Ao final da atividade, espera-se que o aluno seja capaz de:

Criar classes em Java.

Declarar e utilizar atributos privados.

Aplicar o conceito de encapsulamento.

Criar métodos get e set.

Criar construtores.

Utilizar herança entre classes.

Aplicar polimorfismo.

Utilizar sobrescrita de métodos (@Override).

Criar métodos sobrecarregados.

Instanciar objetos.

Manipular objetos por meio de referências da classe pai.

Desenvolver um pequeno sistema utilizando os conceitos fundamentais de POO.
